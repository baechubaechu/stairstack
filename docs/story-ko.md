# STAIRSTACK 세계관 · 문장 초안

> 초안이에요. 마음에 안 드는 줄은 그냥 고쳐 주세요. 확정되면 `src/lib/i18n.js`에 반영합니다.
> `{name}`, `{score}` 같은 중괄호는 게임이 숫자·이름을 채워 넣는 자리라 그대로 둬 주세요.

## 1. 설정

- **무대**: 휴화산 위에 세운 신도시, 초고층 타워 신축 현장. 해 질 녘, 지반 아래에서 분화가 시작된다.
- **플레이어**: 타워크레인 기사. 현장 꼭대기 운전실에 있어서 유일하게 무사하다.
- **드론**: 현장 감시 드론이 작업자를 따라다니며 크레인 운전실로 영상을 보낸다. 기사는 운전실 시야와
  드론 영상, 두 화면으로 작업자를 구한다.
- **구해야 할 사람**: 현장에 혼자 남은 작업자 (헬멧 캐릭터). 엘리베이터는 멈췄고 지상은 용암에 잠기고 있다.
- **목표**: 크레인으로 자재를 내려 작업자가 밟고 오를 길을 만들고, 구조 헬기가 올 때까지 버틴다.
  (끝없는 모드라 헬기는 오지 않는다 — "더 높이"가 계속된다)
- **왜 작업자를 바로 매달아 올리지 못하나**: 분화 진동으로 **크레인 브레이크가 고장**났다. 매단 짐을
  멈춰 세우지 못하고 천천히 미끄러져 내려가다 결국 풀려 떨어진다 — 사람을 걸면 그대로 추락이다.
  그래서 자재만 "떨어뜨려서" 길을 깔 수 있다. (보조: 크레인으로 사람을 드는 건 원래 규정상 금지,
  화산재 때문에 운전실에서는 작업자가 잘 안 보여 드론 영상으로만 본다)

### 게임 요소 ↔ 세계관

| 게임 요소 | 세계관 설명 |
|---|---|
| 평면 (투시) | 크레인 운전실에서 내려다본 현장 — 여기에 자재를 내릴 자리를 고른다 |
| 입면 | 드론 카메라 — 현장 감시 드론이 작업자를 따라다니며 측면에서 찍는 영상. 작업자가 오르면 같이 상승한다 |
| 면 전환 | 작업자가 건물 모퉁이를 돌면 드론도 모퉁이를 돌아 옆 면으로 선회 |
| 떨어지는 부재 | 크레인이 내리는 자재 (갈고리에 매달려 내려오다 풀린다) |
| 자재가 저절로 내려앉음 | 고장 난 브레이크가 밀려서 |
| 갈수록 빨리 내려옴 | 브레이크 고장이 점점 심해져서 |
| 클릭하면 바로 떨어짐 | 기사가 일부러 훅을 푼다 |
| 머리 위 낙하 | 낙하물 사고 |
| 용암 | 분화로 솟는 용암 |
| 현무암 | 용암이 삼킨 자재가 식어 굳은 바위 — 다시 발판이 된다 |
| 점선 바닥판 | 아직 고정 안 된 다음 층 가설 데크 — 작업자가 올라서면 고정 |
| 층 도달 | "N층 확보" |
| 기울기 화살표 | 크레인 기사의 하중 예측 |

## 7. 그대로 둘 것 (세계관과 무관한 UI)

상단 바 버튼(일시정지·음악·재시작·제보하기), 제보 창, 휴대폰 안내, 언어, 조작법 카드 본문은 그대로 두는 걸 추천해요.
조작법 카드만 용어(부재→자재, 평면→운전실 시야, 입면→드론 카메라)를 맞춥니다.

## 8. 화면 연출 (문장 말고 그림)

1. 매단 자재 위로 **크레인 케이블과 갈고리** — 떨어뜨리면 "철컥" 풀린다
   - **브레이크 고장 표현**: 내려가는 동안 케이블이 덜컹거리며 끊기듯 미끄러지고, 갈고리 쪽에서 불꽃이
     살짝 튄다. 분화가 거세질수록(낙하가 빨라질수록) 덜컹임과 불꽃이 잦아진다
2. 층 데크에 올라서면 **"N층 확보" 배너**
3. 하늘에 **타워크레인 실루엣**, 멀리 **분화하는 산과 화산재**
4. 구조 실패 화면에 **사고 기록** 느낌 (현장 일지 서식)
5. **드론 화면 정보**: 입면 가장자리에 `● REC`, 고도 `ALT 12.4m`, 배터리 막대, 모서리 조준 표시
6. 면을 돌 때 화면이 살짝 기울며 **선회**하는 느낌, 화산재가 렌즈를 스치는 효과
7. **용암 사망 연출 (터미네이터 2 오마주)**: 작업자가 용암에 천천히 가라앉으며 마지막에 **엄지를 치켜든 손만**
   남았다가 사라진다. 그 위로 무전 말풍선 `"I'll be back."` → 구조 실패 화면. 머리 위 낙하 사망은 이 연출 없이 그대로

## 9. 구조 실패 연출 — 뉴스 속보

죽는 경우는 두 가지: **용암에 닿음**, **머리 위로 자재 낙하**. 죽는 순간 드론 카메라(입면) 화면을 캡처해
"현장 사진"으로 쓴다. 어느 화면이든 클릭하면 다음으로 넘어간다. 기존 "쓰러진 곳 보기"는 이걸로 대체(삭제).

### 흐름
0. (용암 사망만) 엄지 들고 가라앉기 + `"I'll be back."` — 약 2초
1. **속보 화면** — 약 1~1.5초: 왼쪽 앵커, 오른쪽 현장 사진, 아래 빨간 `속보` 띠 + 헤드라인, 맨 아래 흐르는 뉴스 자막
2. **현장 리포터 화면**: 마이크 든 리포터가 결과를 전함. 하단 자막에 점수·기록, 그 아래 리더보드와 `다시 구조하러`
- 인물 그림: 게임과 같은 도면풍 단순 실루엣 (헬멧 캐릭터와 같은 그림체)
- 이름: 앵커 **박속보**, 리포터 **김현장 기자**

### 헤드라인 (판마다 하나를 무작위로, 숫자는 그 판 기록)

용암
- [속보] 신축 타워 현장 용암 덮쳐… 작업자 지상 {m}m 지점서 고립
- [속보] 분화 {time}초 만에… 크레인 구조 작전 실패
- [속보] 용암 {lava}m까지 차올라… 마지막 무전은 "I'll be back"
- [속보] "용암보다 빨리 쌓아야 했다"… 현장 {floors}층서 멈춘 구조

자재 낙하
- [속보] 브레이크 고장 크레인서 {type} 추락… 작업자 덮쳐
- [속보] "위에 조심!" 무전 직후… 크레인 낙하 사고
- [속보] 구조용 자재가 흉기로… 지상 {m}m 낙하물 사고

### 흐르는 뉴스 자막 (무작위로 이어 붙임)
- 화산폭발 현장에서 사망사고. 산재보험 처리 가능?
- 화산재로 공항 전면 결항
- 시청, 해안가 대피령 발령
- 크레인 기사 "브레이크가 나갔다" 증언
- 내일 날씨: 매우 뜨거움
- 타워 시공사 "공사 기간 연장 불가피"
- 현장 드론 배터리 잔량 12%

### 리포터 대사 (상황에 맞는 문장을 이어 붙임)

1. **여는 말** (무작위 하나)
   - "네, 분화 현장에 나와 있습니다."
   - "네, 김현장 기자입니다. 아직도 이곳은 열기가 대단합니다."
2. **무슨 일이 있었나**
   - 용암: "작업자는 크레인이 떨어뜨려 준 자재를 딛고 지상 {m}m까지 올랐지만, 끝내 차오르는 용암을 피하지 못했습니다."
   - 자재 낙하: "작업자는 지상 {m}m까지 올랐지만, 브레이크가 고장 난 크레인에서 떨어진 {type}에 그만 맞고 말았습니다."
3. **기록**
   - "버틴 시간은 {time}초, 크레인이 내린 자재는 모두 {n}개입니다."
   - 층을 확보했으면: "확보한 층은 {floors}층입니다." / 못 했으면: "아쉽게도 한 층도 확보하지 못했습니다."
4. **결과**: "최종 구조 점수는 {score}점, 전체 크레인 기사 가운데 {rank}위입니다."
   (순위를 불러오지 못하면 이 문장은 "최종 구조 점수는 {score}점입니다."로)
5. **마무리** (해당하는 것 하나)
   - 개인 최고 기록: "이 기사의 개인 최고 기록입니다. 다음 작전이 벌써 기대됩니다."
   - 30초 안에 끝남: "작전은 {time}초 만에 끝났습니다. 현장에서는 '처음엔 다 그렇다'는 말이 나옵니다."
