CAB 07크레인 운전실 UI 무드보드

화면 전체를 타워크레인 운전실 하나로 봅니다. 플레이어는 브레이크가 나간 크레인의 기사이고, 눈앞의 모든 표시는 운전실에 실제로 달려 있을 법한 물건이어야 합니다. 이 페이지는 그 물건들의 색, 글꼴, 재질, 부품을 한곳에 모은 기준판입니다.

지금 화면이 어수선한 이유 DIAGNOSIS

시각 언어

세 가지가 섞여 있습니다. 흰 웹 카드(상단 바, 자재 대기열, 일시정지 메뉴), 둥근 주황 액자(운전실 시야), 어두운 기계 콘솔(계기판). 콘솔만 운전실 물건이고 나머지는 일반 웹사이트 부품입니다.

글꼴

모든 글자가 시스템 기본 글꼴입니다. 라벨, 숫자, 본문이 같은 목소리라 위계가 생기지 않습니다.

색의 뜻

주황이 버튼, 액자, 강조, 안내에 두루 쓰여서 "누를 수 있는 것"이라는 뜻이 흐려졌습니다.

버튼

상단 바의 텍스트 버튼(일시정지·음악 켜기·재시작·제보하기)은 운전실 천장에 있어야 할 스위치인데 웹 링크처럼 생겼습니다.

색: 뜻이 하나씩 PALETTE

색마다 맡는 역할을 하나로 정합니다. 장식으로 쓰는 색은 없습니다.
